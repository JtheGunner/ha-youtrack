## ✨ Planned features

| | Feature | Description |
|---|---|---|
| 📊 | Project statistics | Issue counts per project: total, open, resolved, unassigned, overdue, created and resolved in the last 7 days |
| 🔎 | Query sensors | Turn any YouTrack search query into a sensor with the matching issues as attributes |
| ✅ | To-do lists | Open issues as a native Home Assistant to-do list |
| 🔔 | Activity events | Trigger automations when issues are created, resolved or commented |
| ✍️ | Actions | Create issues, comment, change state, assign and log work from automations |
| 📚 | Knowledge base | Search and read YouTrack articles from scripts and automations |

Each YouTrack instance is configured once; every project you add becomes its own device.

---

## 🧰 Requirements

- Home Assistant 2025.12 or newer
- [HACS](https://hacs.xyz) for installation
- A YouTrack instance reachable from Home Assistant and a [permanent token](https://www.jetbrains.com/help/youtrack/server/manage-permanent-token.html)
